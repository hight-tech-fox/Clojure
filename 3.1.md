# **Параллельная обработка последовательностей**

Реализуйте параллельный вариант filter (не обязательно ленивый) с помощью future.

Параллельная обработка должна производиться блоками по заданному числу элементов. Размер блоков следует вычислять вручную, без использования готовых функций, таких как partition (для разделения последовательности следует использовать take и drop).

Продемонстрируйте прирост производительности в сравнении с обычным фильтром.

(ns main)

(defn split-blocks [items size]
  (loop [items items
         blocks []]
    (if (empty? items)
      blocks
      (recur (drop size items)
             (conj blocks (take size items))))))

(defn parallel-filter [predicate items size]
  (let [blocks (split-blocks items size)
        tasks (mapv (fn [block]
                      (future (vec (filter predicate block))))
                    blocks)]
    (vec (apply concat (map deref tasks)))))

(defn slow-even? [x]
  (Thread/sleep 2)
  (even? x))

(def numbers (range 200))

(println "Standard filter:")
(time (vec (filter slow-even? numbers)))

(println "Parallel filter:")
(time (parallel-filter slow-even? numbers 20))

(println "Results are equal:")
(println (= (vec (filter even? numbers))
            (parallel-filter even? numbers 20)))

(shutdown-agents)
