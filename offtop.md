# **Мини-код для защит лаб**


Защита 1.2.
Задание:какая ошибка и почему происходит, если попытаться написать бесконечный цикл через нехвостовую рекурсию. перепиши одну функцию без loop


**--------------------------------------------------------------------------------------------------------**

Исходная функция:

(defn apply-n-times [n f x]
  (loop [remaining n
         result x]
    (if (zero? remaining)
      result
      (recur (dec remaining)
             (f result)))))

Перепишем:

(defn apply-n-times [n f x]
  (if (zero? n)
    x
    (recur (dec n) f (f x))))
